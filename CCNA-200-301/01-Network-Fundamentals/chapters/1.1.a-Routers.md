# What Is a Router?

A **router** is a **Layer 3 (Network Layer)** device that connects **different IP networks** together.

Unlike a switch, which allows devices on the same network to communicate, a router allows devices on **different networks** to exchange data.

Think of a router as a **GPS for network traffic**. When a packet arrives, the router determines the best path to its destination.

---

## Simple Example

```text
           Internet
               |
               |
        +---------------+
        |    Router     |
        +---------------+
          |           |
          |           |
 192.168.1.0/24   10.10.10.0/24
```

The router connects two different networks and allows devices on each network to communicate.

---

# Why Do We Need Routers?

Imagine two separate neighborhoods.

Each neighborhood has its own roads.

Cars can drive around inside their own neighborhood, but they cannot reach the other neighborhood without a connecting highway.

Networks work the same way.

Devices on the same subnet can communicate directly.

Devices on different subnets require a router.

Example:

```text
Network A
192.168.1.0/24

      PC1
192.168.1.10
      |
      |
   +------+
   |Switch|
   +------+
      |
      |
   +------+
   |Router|
   +------+
      |
      |
   +------+
   |Switch|
   +------+
      |
      |
192.168.2.15
      PC2

Network B
192.168.2.0/24
```

Without the router, PC1 and PC2 cannot communicate because they are on different networks.

# Routers Operate at Layer 3

Routers make forwarding decisions using **IP addresses**.

```text
OSI Model

Layer 7  Application

Layer 6  Presentation

Layer 5  Session

Layer 4  Transport

----------------------------
Layer 3  Network   ← Router
----------------------------

Layer 2  Data Link ← Switch

Layer 1  Physical
```

> **CCNA Exam Tip**
>
> If a question mentions:
>
> - Routing
> - IP addresses
> - Best path
> - Remote networks
>
> The correct answer usually involves **Layer 3**.

# Router vs Switch

| Switch | Router |
|---------|---------|
| Layer 2 | Layer 3 |
| Uses MAC addresses | Uses IP addresses |
| Connects devices within one LAN | Connects different networks |
| Learns MAC address table | Learns routing table |
| Cannot route traffic | Routes traffic |

---

# Router Interfaces

Every router has one or more interfaces.

Each interface belongs to a **different network**.

| Interface | IP Address | Connected Network |
|-----------|------------|-------------------|
| GigabitEthernet0/0 | 192.168.1.1/24 | 192.168.1.0/24 |
| GigabitEthernet0/1 | 10.10.10.1/24 | 10.10.10.0/24 |

Diagram:

```text
          +----------------------+
          |       Router         |
          +----------------------+
          | G0/0       G0/1      |
          |                      |
192.168.1.1          10.10.10.1
     |                    |
     |                    |
LAN 1                LAN 2
```

---

# How a Router Forwards Packets

When a packet reaches a router, the router performs four basic steps.

```text
        Packet Arrives
              |
              v
Read Destination IP Address
              |
              v
Search Routing Table
              |
              v
Choose Best Route
              |
              v
Forward Packet
```

The router looks at the **destination IP address**, not the MAC address.

---

# Default Gateway

Every computer needs a **default gateway**.

The default gateway is usually the router interface connected to the local network.

Example:

| Setting | Value |
|---------|-------|
| IP Address | 192.168.1.25 |
| Subnet Mask | 255.255.255.0 |
| Default Gateway | 192.168.1.1 |

```text
          +---------------+
          |    Router     |
          | 192.168.1.1   |
          +---------------+
                 ▲
                 |
         Default Gateway
                 |
          +---------------+
          |      PC       |
          |192.168.1.25   |
          +---------------+
```

When the PC wants to communicate with another subnet, it sends the packet to the default gateway.

---

# Routing Table

Every router maintains a routing table.

Think of it as the router's map.

```text
Destination Network     Interface

192.168.1.0/24          G0/0

10.10.10.0/24           G0/1

0.0.0.0/0               ISP
```

When a packet arrives, the router searches this table for the best matching route.

---

# Longest Prefix Match

Routers may know multiple routes that match a destination.

The router always selects the **most specific** route.

```text
Known Routes

10.0.0.0/8

10.10.0.0/16

10.10.5.0/24
```

Destination:

```text
10.10.5.25
```

Selected Route:

```text
10.10.5.0/24
```

Because **/24** is more specific than **/16** or **/8**.

---

# Connected Routes

Whenever an interface receives an IP address and is enabled, Cisco IOS automatically creates a connected route.

```cisco
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
```

Routing table:

```text
C 192.168.1.0/24 is directly connected, GigabitEthernet0/0
```

The **C** means **Connected**.

---

# Static Routes

A static route is manually configured by the administrator.

```cisco
ip route 172.16.0.0 255.255.0.0 10.10.10.2
```

Meaning:

> To reach **172.16.0.0/16**, send packets to **10.10.10.2**.

### Advantages

- Simple
- Secure
- Predictable

### Disadvantages

- Manual configuration
- Doesn't scale well
- Must be updated manually

---

# Dynamic Routing

Instead of manually configuring routes, routers can exchange routing information automatically.

| Protocol | CCNA Coverage |
|-----------|---------------|
| OSPF | ✔ Yes |
| RIP | Basic recognition |
| EIGRP | Basic recognition |
| BGP | Recognition only |

Dynamic routing allows routers to:

- Learn new networks automatically
- Recover from failures
- Update routing tables without manual intervention

---

# Administrative Distance (AD)

Administrative Distance determines which routing source is most trustworthy.

Lower values are preferred.

| Route Source | AD |
|--------------|----|
| Connected | 0 |
| Static | 1 |
| eBGP | 20 |
| EIGRP | 90 |
| OSPF | 110 |
| RIP | 120 |

Example:

```text
Network 192.168.50.0/24

Static Route (AD 1)

OSPF Route (AD 110)

Winner:
Static Route
```

# Packet Forwarding

```text
               Packet Arrives
                     |
                     v
          Read Destination IP
                     |
                     v
          Search Routing Table
                     |
                     v
        Matching Route Found?
             /             \
           Yes             No
            |               |
            v               v
     Forward Packet    Use Default Route?
                             |
                       Yes -------- No
                        |            |
                        v            v
                Forward Packet   Drop Packet
```

# Layer 2 Rebuilding

Routers do **not** forward Ethernet frames unchanged.

Instead they:

1. Remove the old Layer 2 frame.
2. Read the IP packet.
3. Choose the outgoing interface.
4. Build a new Layer 2 frame.
5. Forward the packet.

| Field | Changes? |
|---------|----------|
| Source MAC | ✔ Yes |
| Destination MAC | ✔ Yes |
| Source IP | ✘ No |
| Destination IP | ✘ No |

# Real-World Example

Your home PC:

```text
IP Address:
192.168.1.20

Default Gateway:
192.168.1.1
```

When you visit **www.google.com**, your PC sends the packet to the default gateway because Google is on another network.

Your home router checks its routing table and forwards the packet toward your ISP.

Every router on the Internet repeats this process until the packet reaches Google's network.

---

# Common CCNA Mistakes

| Incorrect | Correct |
|------------|---------|
| Routers use MAC addresses to route packets. | Routers use destination IP addresses. |
| Switches replace routers. | Switches connect devices within the same LAN. |
| Default gateways are only for Internet traffic. | They are used for all destinations outside the local subnet. |
| Routers forward Ethernet frames unchanged. | Routers rebuild the Layer 2 frame every hop. |
| The shortest prefix wins. | The longest prefix match always wins. |
