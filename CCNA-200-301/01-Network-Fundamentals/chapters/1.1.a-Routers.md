# What is a Router?

A **router** is a **Layer 3 (Network Layer)** device that connects **different IP networks** together.

Think of a router as a **GPS for data**.

When a packet needs to travel across multiple networks, the router decides:

> "Which path should I send this packet so it reaches its destination?"

Without routers, computers could only communicate with devices on their own local network.

---

## Simple Example

```text
             Internet
                 |
          +---------------+
          |    Router     |
          +---------------+
            |           |
      Office LAN     Wi-Fi LAN
     192.168.1.0    192.168.2.0
```

The router allows both networks to communicate.

---

# Real World Analogy

Imagine sending a package.

You don't know every road between your house and your friend's house.

Instead, you give the package to the post office.

The postal service determines the best route.

A router works exactly the same way.

You give it a packet.

The router figures out where to send it.

---

# Why Do We Need Routers?

Without routers:

```text
PC1 -------- PC2

Only same network communication.
```

With routers:

```text
PC1 ---- Router ---- Internet ---- Router ---- PC2
```

Now devices anywhere in the world can communicate.

---

# What Does a Router Actually Do?

A router performs five major jobs.

| Function | Description |
|----------|-------------|
| Connects Networks | Joins different IP networks together |
| Chooses Best Path | Determines where packets should go |
| Forwards Packets | Sends packets toward destination |
| Separates Broadcast Domains | Stops broadcast traffic between networks |
| Connects to WANs | Connects LANs to the Internet |

---

# Router vs Switch

This is one of the most common CCNA exam topics.

| Switch | Router |
|---------|---------|
| Layer 2 | Layer 3 |
| Uses MAC addresses | Uses IP addresses |
| Connects devices | Connects networks |
| Forwards Ethernet frames | Forwards IP packets |
| Learns MAC table | Builds routing table |

---

## Visual Comparison

### Switch

```text
PC ---\
PC ---- Switch
PC ---/

Everyone is on ONE network.
```

### Router

```text
LAN A ---- Router ---- LAN B
```

Different networks are connected together.

# Broadcast Domains

A router creates separate broadcast domains.

Without a router:

```text
+-------------------------+

PC
PC
PC
PC

Broadcast reaches everyone.
```

With a router:

```text
LAN A

PC
PC
 |
Router
 |
PC
PC

LAN B

Broadcast stops here.
```

Broadcast traffic never crosses a router by default.

> **CCNA Tip**
>
> Routers stop broadcasts.

# Router Interfaces

Every router has interfaces.

Common Cisco interface names:

| Interface | Description |
|-----------|-------------|
| G0/0 | GigabitEthernet0/0 |
| G0/1 | GigabitEthernet0/1 |
| G0/2 | GigabitEthernet0/2 |
| S0/0/0 | Serial interface |
| Loopback0 | Virtual interface |

Example:

```text
          G0/0
LAN -------|
            |
         Router
            |
Internet ---|
          G0/1
```

Each interface belongs to a different network.

Example:

```text
G0/0
192.168.1.1/24

G0/1
10.10.10.1/30
```

---

# Every Interface Has Its Own IP Address

Example:

```text
Router

G0/0
192.168.1.1

G0/1
172.16.10.1

G0/2
10.0.0.1
```

Each interface represents a different subnet.

# What is a Default Gateway?

The **default gateway** is the router that a computer sends traffic to when the destination is outside its own network.

Think of it like the entrance to a highway.

If your destination is outside your neighborhood, you first drive to the highway.

The default gateway is that highway entrance.

Example:

```text
PC

IP Address:
192.168.1.10

Default Gateway:
192.168.1.1
```

When the PC wants to reach:

```text
8.8.8.8
```

It sends the packet to:

```text
192.168.1.1
```

The router takes care of the rest.

---

# How Does a Router Know Where to Send Packets?

Routers use a **routing table**.

Think of it as a GPS route list.

Example:

| Destination Network | Next Hop | Exit Interface |
|---------------------|----------|----------------|
| 192.168.1.0/24 | Connected | G0/0 |
| 10.1.1.0/24 | 10.10.10.2 | G0/1 |
| 0.0.0.0/0 | ISP | G0/1 |

The router checks this table every time a packet arrives.

---

# Packet Forwarding Process

Every packet follows these steps.

```text
Packet Arrives
      │
      ▼
Read Destination IP
      │
      ▼
Search Routing Table
      │
      ▼
Find Best Route
      │
      ▼
Forward Packet
```

---

## Example

Packet destination:

```text
172.16.5.20
```

Routing table:

```text
172.16.0.0/16
Exit Interface: G0/1
```

Result:

```text
Packet leaves G0/1
```

---

# Longest Prefix Match (Very Important)

When multiple routes match a destination, the router always chooses the **most specific route**, also known as the **Longest Prefix Match**.

Example routing table:

| Route | Prefix Length |
|--------|--------------:|
| 10.0.0.0/8 | /8 |
| 10.1.0.0/16 | /16 |
| 10.1.5.0/24 | /24 |

Destination:

```text
10.1.5.100
```

Matches:

- ✅ 10.0.0.0/8
- ✅ 10.1.0.0/16
- ✅ 10.1.5.0/24

The router chooses:

```text
10.1.5.0/24
```

because **/24** is the most specific route.

> **CCNA Tip**
>
> Longest Prefix Match is always checked before metrics.

# Static Routes

Static routes are manually configured by an administrator.

```text
Administrator
      │
      ▼
    Router
```

### Advantages

- Simple
- Secure
- Predictable

### Disadvantages

- Manual configuration
- Doesn't scale well

Cisco IOS example:

```cisco
ip route 192.168.2.0 255.255.255.0 10.1.1.2
```

---

# Dynamic Routing

Instead of manually configuring every route, routers can learn routes automatically.

| Protocol | CCNA 200-301 |
|----------|--------------|
| OSPF | ✅ Yes |
| EIGRP | ❌ No |
| RIP | ❌ No |
| IS-IS | ❌ No |
| BGP | ❌ No |

Dynamic routing automatically adjusts when network paths change.

---

# Connected Routes

Whenever an interface is configured and enabled, Cisco IOS automatically installs a connected route.

Example:

```cisco
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
```

The routing table automatically contains:

```text
C 192.168.1.0/24
```

**C** stands for **Connected**.

---

# Default Route

The default route is used when no specific route matches the destination.

```text
0.0.0.0/0
```

This is called the **Gateway of Last Resort**.

```text
Unknown destination?
        │
        ▼
Use Default Route
```

---

# Administrative Distance (Know the Concept)

If the router learns the same route from different sources, it uses **Administrative Distance (AD)** to determine which source is more trustworthy.

| Route Source | Administrative Distance |
|--------------|------------------------:|
| Connected | 0 |
| Static | 1 |
| OSPF | 110 |

Lower values are more trusted.

---

# Routing Metrics

If two routes come from the same routing protocol, the router compares metrics.

Examples include:

- Bandwidth
- Delay
- Cost
- Hop Count

Remember the route selection order:

1. Longest Prefix Match
2. Administrative Distance
3. Routing Metric

---

# Packet Encapsulation Through a Router

A router removes the old Layer 2 frame and creates a new one for the next network.

```text
PC1
 |
 | Ethernet Frame #1
 |
Router
 |
 | Ethernet Frame #2
 |
Server
```

| Field | Changes? |
|--------|----------|
| Source MAC Address | ✅ Yes |
| Destination MAC Address | ✅ Yes |
| Source IP Address | ❌ No |
| Destination IP Address | ❌ No |

> **CCNA Tip**
>
> Routers rewrite Layer 2 headers but normally leave Layer 3 IP addresses unchanged.

# Key Terms

| Term | Definition |
|------|------------|
| Router | Connects different IP networks |
| Routing Table | Database of known routes |
| Default Gateway | Router used to leave the local network |
| Connected Route | Route automatically learned from an active interface |
| Static Route | Route manually configured |
| Dynamic Route | Route learned automatically |
| Longest Prefix Match | Most specific matching route |
| Administrative Distance | Trust value of a routing source |
| Metric | Value used to select the best path |
| Default Route | Used when no other route matches |

---

# CCNA Exam Tips

- Routers operate at **OSI Layer 3**.
- Routers make forwarding decisions using the **destination IP address**.
- Routers connect **different networks**.
- Switches connect **devices on the same network**.
- Routers stop **Layer 2 broadcasts**.
- Every router interface belongs to a different subnet.
- Remote traffic is sent to the **default gateway**.
- Route selection order:
  1. Longest Prefix Match
  2. Administrative Distance
  3. Routing Metric
- Routers rewrite Layer 2 headers at every hop.

# Summary

A router is a Layer 3 device that connects different IP networks. It examines the **destination IP address** of every packet, consults its **routing table**, selects the **best path**, and forwards the packet through the correct interface. Routers also separate broadcast domains, provide the default gateway for hosts, and connect local networks to remote networks such as the Internet.

Understanding routers is one of the most important foundational topics for the CCNA 200-301 exam and prepares you for future topics including static routing, OSPF, IPv6 routing, and route selection.
